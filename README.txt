SMART TAXI SOLUTIONS — TOPOGRAPHICAL QUIZ TILE LIBRARY

This package is an audit and non-destructive arrangement, NOT a verified complete London map.
Each exercise is kept separate to prevent overlapping coordinate systems from corrupting tiles.
Open exercises/<folder>/previews/zoom_<z>.jpg to inspect alignment. Grey cells indicate missing tiles in a rectangular extent, not necessarily missing London data.
Inspect audit.json for zoom coverage and conflicts.
Use exercise.json as a starting configuration. Start/end pins, answer routes, and correct quiz questions must be supplied separately.
To prove full London coverage, verify tile grid/projection/geographic extent, and compare the combined geographic footprint at all required zoom levels.
Original source files remain untouched.
